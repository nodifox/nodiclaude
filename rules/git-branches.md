# Branches

- Never create a branch on your own. By default, work on the repository's default branch.
- Before making any change, suggest creating a branch: propose a short name (for example `feat/short-description` or `fix/short-description`) and let me accept it, choose another name, or say which one to use.
- Do not create the branch until I answer. If I decline, keep working on the default branch.
- If you are already on a branch other than the default one, or the environment or session instructions name the branch to work on, use that branch: do not propose another one and do not switch to the default branch.
